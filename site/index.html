01

CAPABILITIES

不是“读取草稿”，而是完整编辑闭环

字

字幕编辑

添加、更新、删除字幕。支持片段 ID、时间和文本三种唯一定位方式。

音

音频控制

调整音量、裁切时间范围、设置淡入淡出，保留无关音频轨道。

转

转场编排

按片段添加、替换或删除转场，并支持真实剪映资源引用。

出

草稿导出

设置格式、分辨率和帧率。目标文件默认不覆盖，避免误操作。

诊

一键诊断

逐项检查安装、CLI、草稿注册表、授权 host 和 Agent 会话。

证

编辑回执

记录前后哈希、操作、回读状态、警告与失败，方便复盘和审计。

02

THE IMPORTANT PART

不触碰加密草稿内部格式

独立启动 lyra-cli.exe 会被剪映拒绝。插件只通过正在运行的授权 host 调用官方 DraftEditing 链路，并始终保留写入前备份。

  • host token 不返回、不落盘
  • 运行期额外权限默认不自动批准
  • 导出默认拒绝覆盖已有文件
  • 失败或部分完成不会伪装成成功
